# HomoRoboNet 🤖👤
### Deep Learning for Recognition of Humans vs AI-Generated Face Images

**Tafila Technical University | Computer Science Dept. | Fall 2024-2025**

---

## 📌 About
A CNN-based system to detect AI-generated (StyleGAN) faces 
from real human photographs.

## 📊 Datasets
| Dataset | Type | Size |
|---------|------|------|
| CelebA | Real faces | ~202,599 images |
| ThisPersonDoesNotExist | AI-generated | 10,000 images |
